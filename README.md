# Mashiro Android

Неофициальный Android-клиент для Яндекс Музыки.

Проект основан на оригинальном десктопном клиенте [yandex-music-client](https://github.com/aeviww/yandex-music-client) от **@aeviww**.

Приложение построено на базе **Tauri 2 Mobile**: интерфейс написан на Vue 3, сетевая логика и обработка данных — на Rust, а воспроизведение аудио вынесено в нативный Android-сервис на базе ExoPlayer (Jetpack Media3). Благодаря этому музыка стабильно играет в фоне, не выгружается системой и управляется из системной шторки.

---

## Возможности

- **Каталог и рекомендации**: поддержка «Моей волны», персональных подборок, плейлистов, исполнителей и поиска.
- **Честный фоновый плеер**: нативный сервис на базе ExoPlayer. Музыка не прерывается при выключенном экране, есть виджет в шторке, управление с экрана блокировки и гарнитуры.
- **Синхронизированные тексты**: караоке-тексты песен через сервис LrcLib и статьи/факты о треках с Genius.
- **Фильтр нейросетевых треков (Slopless)**: распознавание сгенерированной ИИ музыки и возможность автоматически пропускать такие треки в «Моей волне».
- **Обход цензуры (FckCensor)**: автоматическая подмена треков с цензурой на оригинальные (Explicit) версии из открытой базы.
- **Wi-Fi синхронизация**: встроенный локальный сервер, позволяющий передавать свою музыку (MP3, FLAC, OGG) с компьютера на телефон через веб-интерфейс в браузере.
- **Совместное прослушивание (Together)**: комнаты синхронного воспроизведения музыки с друзьями через P2P.

## Стек технологий

- **Фронтенд**: Vue 3 (Composition API), Quasar Framework, Tailwind CSS, TypeScript
- **Ядро**: Rust, Tokio, Tauri 2 Mobile IPC
- **Аудиосистема**: Kotlin, Jetpack Media3 (ExoPlayer), Foreground Service

## Требования для сборки

- **Node.js** (версии 18, 20 или 22) и **npm**
- **Rust** (актуальная стабильная версия)
- **JDK 17** (например, Eclipse Temurin)
- **Android SDK** (API 34+) и **Android NDK** (26.x или 27.x)

Установка мобильного таргета для Rust:
```bash
rustup target add aarch64-linux-android
```

Переменные окружения (должны указывать на установленные SDK/NDK/JDK):
- `ANDROID_HOME`
- `NDK_HOME`
- `JAVA_HOME`

## Сборка и установка

1. **Клонирование репозитория и установка зависимостей:**
   ```bash
   git clone https://github.com/aeviww/yandex-music-client.git mashiro-android
   cd mashiro-android
   npm install
   ```

2. **Сборка APK:**
   ```bash
   # Стандартная сборка под 64-битный ARM (большинство телефонов)
   npm run android:build:release

   # Универсальный APK со всеми архитектурами (arm64, armv7, x86_64)
   npm run android:build:universal

   # Сборка под 32-битный ARM (старые смартфоны)
   npm run android:build:arm

   # Сборка под x86_64 (эмуляторы Android Studio, ChromeOS)
   npm run android:build:x86_64

   # Или отладочная сборка
   npm run android:build:debug
   ```

   Собранный файл появится по пути:
   `src-tauri/gen/android/app/build/outputs/apk/<arch>/release/app-<arch>-release.apk`

3. **Установка на устройство через ADB:**
   ```bash
   npm run android:install:release
   ```

## Важная информация

- Проект является форком и адаптацией десктопного клиента [yandex-music-client](https://github.com/aeviww/yandex-music-client).
- Большая часть кода написано LLM моделями.
- Проект является независимой разработкой и никак не связан с компанией Яндекс.
- Для прослушивания музыки в высоком качестве требуется аккаунт с активной подпиской Яндекс Плюс.
- Исходный код распространяется под лицензией [GPL-3.0](LICENSE).
