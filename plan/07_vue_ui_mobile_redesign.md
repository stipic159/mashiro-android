# 07. Адаптация и мобильный редизайн интерфейса (Vue Beauty)

В данном документе описывается перенос визуального стиля и интерфейсных компонентов оригинального Mashiro на мобильный экран: организация навигации, адаптивность, анимации, жесты и сохранение визуальной эстетики.

---

## 1. Сохранение визуальной эстетики Mashiro

Интерфейс Mashiro v2 выделяется среди конкурентов минимализмом, продуманной типографикой и премиальной палитрой. На Android сохраняются все фирменные черты:
- **11 встроенных тем оформления**: OLED (глубокий черный для AMOLED), Black, Graphite, Slate, Midnight, Forest, Plum, Warm, Light, Paper, Sky, а также Custom с произвольным цветом фона.
- **8 акцентных цветов**: Pink (`#ff2d8d`), Red, Purple, Blue, Cyan, Green, Orange, Yellow.
- **Динамический фоновый Glow**: размытые светящиеся акценты на основе палитры текущей обложки альбома (Glassmorphism и Backdrop Blur).
- **Плавные микроанимации**: покачивание обложки при воспроизведении, пульсация кнопок, мягкое появление списков.

## 2. Мобильный каркас: `MobileLayout.vue`

Десктопный каркас `MainLayout.vue` со стационарным сайдбаром и окном заголовка заменяется на мобильный лейаут:

```text
+--------------------------------------------------+
|  Status Bar (Safe Area Top: 44dp)                |
+--------------------------------------------------+
|  Хедер страницы: Название раздела / Поиск / Аватар|
+--------------------------------------------------+
|                                                  |
|  Контентная область (Scroll View):               |
|  - Сетка плейлистов                              |
|  - Горизонтальные карусели релизов               |
|  - Список треков с touch-таргетами               |
|                                                  |
+--------------------------------------------------+
|  Плавающий Мини-Плеер (высота 60dp)              |
|  [Обложка] Название - Артист (AI / Expl) [Play]  |
|  ==================== Прогресс ================= |
+--------------------------------------------------+
|  Нижняя панель навигации (Bottom Nav: 56dp)      |
|   [Главная]  [Волна]  [Поиск]  [Коллекция] [Настр]|
+--------------------------------------------------+
|  Gesture Navigation Pill (Safe Area Bottom)      |
+--------------------------------------------------+
```

### 2.1. Поддержка Edge-to-Edge и вырезов (Safe Area Insets)
Для корректного отображения на экранах с «челками» и круглыми вырезами под фронтальную камеру используются системные переменные CSS:
```css
.app-container {
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
  padding-left: env(safe-area-inset-left);
  padding-right: env(safe-area-inset-right);
}
```

## 3. Ключевые мобильные компоненты

### 3.1. Нижняя навигация (`MobileBottomNav.vue`)
Панель фиксируется внизу экрана с фоновым размытием (`backdrop-filter: blur(20px)`):
- 🏠 **Главная**: Рекомендации, персональные подборки, свежие релизы.
- 🌊 **Моя волна**: Интерактивный экран потока с анимированным визуализатором звука и кнопками реакций («Нравится», «Не нравится», настройки настроения).
- 🔍 **Поиск**: Поиск с мгновенными саджестами (`search_suggest`), категориями и фильтром ИИ-слопа.
- 🎵 **Коллекция**: Любимые треки, скачанные оффлайн-песни, плейлисты и артисты.
- ⚙️ **Настройки**: Управление аккаунтом, темами, качеством звука, FckCensorData, Slopless и Wi-Fi синхронизацией.

### 3.2. Док-миниплеер (`MobileMiniPlayer.vue`)
- Располагается прямо над нижней панелью навигации.
- Отображает круглую обложку с анимацией вращения/винила, бегущую строку, бейджи (`AI`, `EXPLICIT`, `LOCAL`).
- **Свайп влево**: Переключение на следующий трек.
- **Свайп вправо**: Возврат к предыдущему треку.
- **Свайп вверх или тап**: Плавное раскрытие полноэкранного плеера.

### 3.3. Полноэкранный плеер (`MobileFullscreenPlayer.vue`)
- Раскрывается на весь экран поверх интерфейса с физической spring-анимацией.
- Крупная обложка альбома с мягкими скругленными краями (24px) и тенью цвета доминирующего оттенка трека.
- Интерактивный слайдер времени с крупной областью захвата пальцем (touch-target 48dp).
- Кнопки управления: «Перемешать», «Предыдущий», акцентная кнопка «Воспроизведение/Пауза» увеличенного размера (64dp), «Следующий», «Повтор».
- Быстрый переключатель версий: мгновенный тап для переключения между версией без цензуры и радио-версией.

### 3.4. Экран караоке-текста песен (LRC Lyrics)
- Переключение свайпом влево в полноэкранном плеере.
- Построчный текст с синхронизацией по миллисекундам.
- Активная строка подсвечивается акцентным цветом и плавно центрируется на экране.
- Возможность нажать на любую строчку текста для мгновенной перемотки музыки к этому моменту.
- Интеграция с встроенным переводчиком `translate_lines` из Rust: кнопка показа построчного перевода на русский язык и романизации для иностранных треков.

### 3.5. Мобильные шторки действий (`TrackBottomSheet.vue`)
Вместо контекстных меню по правой кнопке мыши все действия открываются в плавной нижней шторке (Bottom Sheet):
- Добавить в плейлист / убрать.
- **«Заменить своей версией (с ПК или файла)»**.
- **«Переключить версию без цензуры (FckCensorData)»**.
- Перейти к исполнителю / к альбому.
- Поделиться ссылкой на трек.
- Скачать для оффлайн-прослушивания.

## 4. Мобильные жесты, тактильный отклик и системная кнопка «Назад»

1. **Тактильный отклик (Haptic Feedback)**:
   - Использование Android `Vibrator` / `HapticFeedbackConstants`:
   - Легкий щелчок (`CLOCK_TICK`) при смене трека или перемотке.
   - Четкий отклик (`CONFIRM`) при нажатии кнопки «Лайк» или сохранении подмены трека.
2. **Обработка системного жеста «Назад» (Android Back Gesture)**:
   - Если открыт полноэкранный плеер -> закрыть плеер свайпом вниз.
   - Если открыта шторка трека или диалог -> закрыть шторку.
   - Если пользователь находится на странице альбома/артиста -> вернуться назад в истории `vue-router`.
   - Если на главной вкладке -> свернуть приложение в фон (музыка продолжает играть в фоне через `MashiroMediaService`).
